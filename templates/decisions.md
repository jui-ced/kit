# 업무 판단과 진행 기록

이 문서의 질문 대상은 **Probe 내부 메신저의 업무 담당자·실무자 에이전트**입니다. 외부 사람에게 연락하거나 문제·코드·작업물을 전달하지 않습니다.

이 문서는 어떤 문제를 중요하게 보았고, 실무자 에이전트에게 무엇을 확인했으며, 사용자가 왜 그 범위·우선순위를 선택했고 작업이 어떻게 진행되었는지 기록한다. 알고리즘·기술적 선택의 상세 근거는 [skill.md](skill.md)에 작성한다. 기술 선택은 여기에는 요약과 기술 ID만 남기고 비교·원리·측정을 중복 작성하지 않는다. 과제에 복사한 뒤에는 실제 기록 파일 위치로 링크를 바꾼다.

구현 중 기록하고, 완료 후 후속 설명 단계 전에 실제 기록을 바탕으로 아래 요약을 정리한다. 사실·실무자 에이전트 의견·AI 추천·사용자 판단을 구분하며 미확인 사항을 채워 넣지 않는다. 실제 후속 문항이 아닌 이해를 위한 준비 자료이며 후속 단계의 AI·자료 열람 규칙은 운영 안내를 따른다.

- 본인이 직접 판단·확인한 내용 / AI가 제안하거나 수행한 내용:

## 사용자 판단 기록
업무 범위·우선순위·가중치·허용 위험 등 중요한 결정마다 아래를 작성한다. AI 추천은 사용자 선택을 대신하지 않는다. 알고리즘 후보에 대한 상세 비교·선택은 skill.md에 기록하고 여기에는 관련 기술 ID를 연결한다.

- 결정 ID / 해결하려는 요구사항:
- 결정할 질문:
- README·데이터·실무자 에이전트 답변의 근거:
- 자료 간 충돌 또는 불확실성:
- 선택지 A / 이익·비용·위험:
- 선택지 B / 이익·비용·위험:
- AI 추천과 이유:
- 사용자에게 실제로 물은 질문:
- 사용자 선택과 본인이 설명한 이유 (답변 전에는 결정 대기):
- 중요하게 본 기준·가중치와 그 이유 (수치가 필요할 때만):
- 포기한 범위와 허용한 위험:
- 반영할 코드·계획·테스트:

- 실제 검증 결과:

사용자에게 묻는 형식: “확인한 사실은 [근거]입니다. A는 [이익/비용], B는 [이익/비용]입니다. 저는 [이유]로 A를 추천합니다. 이번 과제에서는 어느 쪽을 더 중요하게 보고 선택하시겠어요? 이유도 알려주세요.”
