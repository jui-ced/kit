# 오류 수정
실행 명령: [명령]
입력과 환경: [입력·버전]
기대 결과: [내용]
실제 결과와 오류 로그: [내용]

먼저 오류를 재현하고 관찰 사실과 원인 가설을 구분해줘.
재현할 수 없으면 부족한 정보를 명시해줘. 근거 없이 원인을 단정하지 마.
요구사항을 유지하는 최소 수정으로 해결하고 재현 테스트와 관련 회귀 테스트를 실행해줘.
실행 명령·종료 코드·실제 결과·남은 문제를 기록해줘.

오류를 조사하다가 '정상 결과가 무엇인지' 또는 업무 규칙·예외 처리 기준이 애매하면, 기술적 오류로 단정해 고치기 전에 현직자에게 확인할 구체적인 질문을 즉시 내게 제시해줘.
관찰한 입력·실제 결과, 모호한 점, 질문 이유, 답변에 따라 달라질 수정 방향을 함께 설명해줘.
확인이 필요한 처리 변경은 보류하고 독립적인 재현·원인 조사는 계속해줘. 현직자 답변 후에도 우선순위·절충안 판단이 필요하면 선택지와 근거를 정리해 나에게 물어봐.
