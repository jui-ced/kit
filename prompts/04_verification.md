# 실제 검증

이 문서의 질문 대상은 **Probe 내부 메신저의 업무 담당자·실무자 에이전트**입니다. 외부 사람에게 연락하거나 문제·코드·작업물을 전달하지 않습니다.
시험 요구사항과 구현물을 비교하고 각 요구사항의 검증 상태를 정리해줘.
정상 입력, 빈 데이터, 누락값, 잘못된 형식, 경계값, API 오류 중 관련 항목을 직접 테스트해줘.
실행 명령·기대 결과·실제 결과·종료 코드를 기록하고 통과/실패/미실행을 구분해줘.
입력 보존, 파일명·경로, 출력 형식, 재실행 가능성도 확인해줘.
도구의 정상 실행과 결과 내용의 정확성을 따로 확인해줘.
실패를 숨기거나 미실행 테스트를 통과로 쓰지 말고, 큰 수정이 필요하면 먼저 범위를 설명해줘.
templates/test_report.md 형식을 참고하되 기록은 과제 작업 공간에 남겨줘.

실무자 에이전트에게 확인한 성공 기준·예외와 내가 선택한 우선순위가 테스트에 반영되었는지 대조해줘.
templates/skill.md의 사용자 선택과 실제 알고리즘·설정이 일치하는지 확인해줘. 후보 효율을 비교했다면 동일 목표·제약·데이터·시간 측정 범위인지, 해가 유효한지, 이론적 설명과 실제 수치가 분리되어 있는지 확인해줘. 측정 로그와 한계를 추가하고, 결과 때문에 알고리즘을 바꿔야 한다면 비교 근거를 보여준 뒤 내 선택을 물어봐.
기술적으로는 통과해도 업무상 맞는지 불명확한 결과는 실무자 에이전트에게 물을 구체적 질문으로 정리해줘.
남은 오류를 수정할지, 범위를 줄일지, 한계로 명시할지 판단이 필요하면 영향·선택지·추천을 제시하고 나에게 선택과 이유를 물어봐.
