# 실제 검증
시험 요구사항과 구현물을 비교하고 각 요구사항의 검증 상태를 정리해줘.
정상 입력, 빈 데이터, 누락값, 잘못된 형식, 경계값, API 오류 중 관련 항목을 직접 테스트해줘.
실행 명령·기대 결과·실제 결과·종료 코드를 기록하고 통과/실패/미실행을 구분해줘.
입력 보존, 파일명·경로, 출력 형식, 재실행 가능성도 확인해줘.
도구의 정상 실행과 결과 내용의 정확성을 따로 확인해줘.
실패를 숨기거나 미실행 테스트를 통과로 쓰지 말고, 큰 수정이 필요하면 먼저 범위를 설명해줘.
templates/test_report.md 형식을 참고하되 기록은 과제 작업 공간에 남겨줘.
