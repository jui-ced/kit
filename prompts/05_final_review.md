# 제출 전 최종 점검
시험 README의 제출 조건과 실제 제출 파일을 하나씩 대조해줘.
필수 기능·실행 방법·의존성·테스트 결과·미해결 문제·외부 코드 출처가 설명되어 있는지 확인해줘.
임시 파일·비밀 값·불필요한 kit 파일이 제출물에 섞이지 않았는지 확인해줘.
새 기능은 추가하지 말고 제출을 막는 문제만 알려줘.
입력 → 처리 → 출력, 선택 이유, 직접 검증한 내용, 한계를 내가 설명할 수 있도록 요약해줘.
후속 설명 단계 시작 전에 과제 작업 공간의 decisions.md(업무 판단·진행)와 skill.md(기술 설명) 앞부분을 실제 기록에 근거한 읽기 쉬운 요약으로 정리해줘. 기술 용어는 쉬운 뜻을 덧붙이고 근거 코드·테스트 위치를 연결해줘. 두 문서의 자기 점검 질문으로 내가 설명할 수 있는 부분과 아직 모르는 부분을 확인하되, 실제 출제 문항이나 수행하지 않은 판단·검증을 만들어내지 마.
제출 완료 여부는 실제 확인한 범위만 말해줘. 후속 서술형 단계에서는 AI 지원을 중단해줘.
