# 요구사항 분석
시험 README와 제공 자료, kit/AGENTS.md를 읽고 아래를 정리해줘.
1. 필수 기능과 선택 기능 (근거 파일·위치 포함)
2. 제출 파일명·경로·형식
3. 허용 기술·설치·네트워크·시간 제약
4. 우선 구현할 MVP와 작업 순서
5. 각 요구사항의 입력·기대 출력·검증 방법
6. 확인되지 않은 사항과 확인 방법
7. 현직자에게 확인할 업무 질문: 각 질문에 현재 관찰, 구체적 질문, 답변에 따라 바뀔 결정을 붙여줘. templates/stakeholder_questions.md를 참고해 영향이 큰 3~5개부터 제시해줘.
8. 내가 개발자로 판단해야 하는 항목: MVP 범위, 중요도·가중치, 오류 허용 수준, 시간과 정확성의 절충을 구분해줘. 근거와 선택지·장단점·추천을 제시한 뒤 나에게 선택과 이유를 물어봐. 임의로 확정하지 마.

내가 현직자 답변을 전달하면 사실과 해석을 구분하고 후속 질문을 만들어줘.
현직자 의견을 공식 배점으로 간주하지 말고, 필수 조건을 충족하면서 내가 우선순위를 판단하도록 도와줘.
미답변 질문과 결정 대기 항목, 그와 무관하게 진행할 수 있는 작업을 구분해줘.

아직 코드를 수정하지 마. 요구사항·데이터를 임의로 만들지 마.
kit은 보조 도구이며 실제 과제 폴더와 구분해줘.
